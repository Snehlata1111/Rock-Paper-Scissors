# Rock Paper Scissors

A responsive and interactive Rock Paper Scissors game built with HTML, CSS, and JavaScript. Play against the computer with an intuitive interface and responsive design.

## Live Demo

[Play Rock Paper Scissors](https://rockpaperscissor-silk.vercel.app/)

## Overview

### Features

- Play Rock Paper Scissors against the computer
- Dynamic score tracking
- Interactive choice buttons and hover states
- Responsive layout for different screen sizes
- Visual feedback for player and computer choices
- Reset and replay functionality



## Tech Stack

- HTML5
- CSS3
- JavaScript

## Project Highlights

- Implemented the complete Rock Paper Scissors game logic using JavaScript.
- Created responsive layouts and interactive UI elements using CSS.
- Added dynamic game states, score updates, and computer-generated choices.
